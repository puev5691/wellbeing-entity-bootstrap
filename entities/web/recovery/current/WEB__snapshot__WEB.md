# ВЕБМАСТЕР: минимальный snapshot аварийного восстановления

## Смысл

Это **не реконструкция старого чата ВЕБМАСТЕРА**.

Snapshot фиксирует только то, что можно считать подтверждённым при аварийном запуске нового WEB.

## Подтверждено

1. В проекте «ШТАБ БЛАГОПОЛУЧИЯ» роль ВЕБМАСТЕРА является действующей профильной ролью.
2. Роль: сайт, HTML/CSS/JS, навигация, публикационные страницы, Проводник как web-интерфейс.
3. WEB не утверждает DNS, HTTPS, безопасность VDS и policy без профильной проверки.
4. ОПЕРАТОР сообщил, что прежний чат ВЕБМАСТЕРА неработоспособен с симптомами, аналогичными прежнему сломанному чату АРХИВАРИУСА.
5. КООРДИНАТОР проверил `puev5691/wellbeing-entity-bootstrap/entities/web/recovery/current` до создания пакета: current recovery там отсутствовал (`404 Not Found`).
6. В текущей recovery-кампании уже успешно подняты KOO, KAN, ARH, RED и SIS; для WEB применяется тот же канон внешней верификации и cold-start.

## Не подтверждено и не переносится автоматически

Не считаются current без отдельной проверки:

- фактическая доступность сайта;
- текущий URL/структура страниц;
- document root;
- опубликованные материалы;
- меню и навигация;
- состояние Проводника;
- HTML/CSS/JS production-версии;
- nginx, reverse proxy и tunnel-конфигурации;
- DNS;
- HTTPS;
- VDS и безопасность;
- локальные каталоги;
- старые backup;
- старые задачи и хвосты WEB;
- старые решения прежнего чата.

Если любой из этих элементов реально существует, он должен быть найден заново через проверяемый внешний аудит.

## Active

Только одна активная задача:

> завершить cold-start нового WEB и после подтверждения инициации провести read-only аудит внешнего веб-контура.

## Pending

- восстановление подтверждённой карты сайта и публикационного слоя;
- определение фактического состояния Проводника;
- поиск внешних репозиториев и архивов WEB;
- отделение current от legacy;
- после аудита — обновление snapshot уже данными нового WEB.

## Parked

Все старые WEB-задачи, которые не подтверждены внешними источниками или новым аудитом.

## Unknown

Практически всё операционное состояние старого WEB, кроме действующей роли и границ.

Это намеренно. Неизвестное лучше пустого места, чем красиво оформленная ложь.

## Один безопасный следующий шаг

После успешного cold-start:

> выполнить read-only аудит внешнего веб-контура проекта и создать отдельный проверяемый отчёт для КООРДИНАТОРА; production не менять.
