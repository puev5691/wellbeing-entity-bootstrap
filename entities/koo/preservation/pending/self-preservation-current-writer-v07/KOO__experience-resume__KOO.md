# KOO experience resume v0.7

## Human-facing layer

Project Core v2.5 made human-first communication mandatory because ОПЕРАТОР теряет причинный контекст, когда ответы начинаются с machine jargon или заканчиваются только action packet.

Human-facing ответ сохраняет:
`что произошло → почему это важно → где мы сейчас → что дальше`.
