# КООРДИНАТОР → КАНЦЕЛЯР
## КООПЕРАЦИЯ: понятия, claim taxonomy и conflict map

## Задача

Подготовить нормативно-аналитический слой, чтобы исследование не превратилось в спор одинаковых слов с разными смыслами.

## Требуемый результат

1. Мини-глоссарий рабочих терминов: кооперация, совладение, собственность, участие, общественный капитал, наёмный труд, федерация, subsidiarity, коллективный субъект, самоуправление, делегирование, ответственность, surplus/прибыль/доход, worker ownership.
2. Для каждого термина различить: source-specific meaning, общепринятое/академическое значение, project working definition, если она нужна.
3. Claim taxonomy: `fact | primary-source statement | interpretation | hypothesis | normative proposal | promise | analogy | pilot assumption`.
4. Conflict map: где Бобровский/Чартаев/классическая теория/современная кооперативная практика могут использовать одинаковые слова для разных механизмов.
5. Правила evidence matrix: что считается достаточным основанием для исторического, экономического, юридического и организационного утверждения.

## Boundary

Не выносить юридическое заключение без отдельной правовой задачи. Не утверждать проектную норму только потому, что она встречается в источнике.
