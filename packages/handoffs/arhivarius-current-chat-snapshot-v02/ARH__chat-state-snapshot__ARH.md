- каждая устойчивая Сущность должна иметь актуальный файл инициации;

- факт внешнего сохранения должен проверяться;
- recovery-пакет должен сохранять незавершённые маршруты;
- новый чат должен иметь возможность продолжить работу без реконструкции по памяти.

Из материала выделены механизмы, которые имеют смысл исследовать отдельно от исторической оболочки:

- субсидиарность;
- локальное рассмотрение вопросов там, где есть знание контекста и короткая обратная связь;
- примирение и восстановление работоспособности отношений;
- гласность и проверяемый след;
- внешний наблюдатель из соседней автономной единицы;
- разделение коллективного содействия и коллективной виновности;
- временный орган под функцию;
- сочетание права участия с обязанностями по поддержанию общего ресурса.

Эти пункты являются исследовательскими кандидатами, а не утверждёнными правилами.

Триггеры:

- проектирование реального Узла Благополучия;
- внутренний механизм разрешения конфликтов;
- локальное самоуправление;
- делегирование полномочий;

- новый сильный первичный или академический источник.
