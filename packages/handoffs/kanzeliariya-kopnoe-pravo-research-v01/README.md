# Копное право: исследовательский модуль КАНЦЕЛЯРИИ

## Краткий смысл

Этот пакет сохраняет исследовательский корпус по копному праву и его возможной связи с архитектурой проекта «БЛАГОПОЛУЧИЕ».

Материал **не является каноном, действующим правом, юридической моделью Узла или готовым регламентом**. Его рабочий статус:

`research / parked_with_trigger`

Исследование возвращается в активную работу только при возникновении прикладного триггера: проектирование реального Узла, внутреннего разрешения конфликтов, локального самоуправления, делегирования полномочий, внешнего наблюдения между автономными Узлами, разработка субсидиарности/компетенции/примирения либо появление нового сильного первичного или академического источника.

## Решение АРХИВАРИУСА

Материал принят как значимый исследовательский корпус и сохранён без перевода в активный канон проекта.

Рациональное ядро для дальнейшей проверки:

- субсидиарность: решение на низшем достаточном уровне;
- локальное знание обстоятельств и короткая обратная связь;
- примирение и восстановление работоспособности отношений;
- открытость процедуры и проверяемый след;
- разделение коллективного содействия и коллективной виновности;
- внешний наблюдатель из соседней автономной единицы как возможная защита от локального сговора;
- временный орган под функцию вместо самовоспроизводящейся бюрократии;
- связь прав участия с обязанностями по поддержанию общего ресурса.

Не канонизировать без следующего цикла проверки:

- исторические обобщения за пределами подтверждённой источниковой базы;
- прямой перенос копной юрисдикции в современность;
- «Круг Узла» как готовый правовой институт;
- выводы о современном праве без актуальной профильной проверки;
- гипотезы о сравнительной эффективности механизмов до контрпримеров и пилотов.
