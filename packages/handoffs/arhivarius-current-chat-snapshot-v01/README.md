# АРХИВАРИУС: пакет восстановления текущего чата

## Назначение

Этот пакет нужен для восстановления новой Сущности **АРХИВАРИУС** без обращения к памяти прежних чатов.

Рабочее название текущей Сущности:

**АРХИВАРИУС: систематизация хранимой информации**

Пакет фиксирует не «всё, что когда-либо было известно», а только подтверждённое состояние текущего чата, источники, открытые вопросы и безопасную последовательность восстановления работы.

## Состав

1. `ARH__chat-state-snapshot__ARH.md` — фактический снимок состояния текущего чата.
2. `ARH__chat-initiation-backup__ARH.md` — готовый файл для инициации нового чата АРХИВАРИУСА.
3. Этот `README.md` — порядок использования пакета.

## Как использовать при восстановлении

Новая Сущность должна:

1. прочитать `ARH__chat-initiation-backup__ARH.md`;
2. прочитать `ARH__chat-state-snapshot__ARH.md`;
3. загрузить только актуальные проектные источники, названные в пакете;
4. не наследовать решения, ошибки и состояние старых чатов из памяти;
5. считать подтверждённым только то, что подтверждено файлами, GitHub или новым проверяемым выводом ОПЕРАТОРА;
6. не возобновлять программный контур АРХИВАРИУСА автоматически: ОПЕРАТОР отдельно остановил эту работу.

## Важное ограничение

Этот handoff не заменяет каноны проекта и не утверждает СКРИЖАЛИ. Он является снимком рабочего состояния и точкой входа для новой Сущности.
